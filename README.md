# プロジェクト工程ボード

複数プロジェクトの進み具合を、1プロジェクト＝1行の「横一列」ガントチャートで見渡すための Web アプリです。
営業・メカ・電気・CS（カスタマーサポート）の担当と工程を、1行の中に色分けして表示します。

- 開発環境: Node.js + React (Vite)
- データはブラウザの localStorage に保存されます（サーバー不要・インストール不要）

## 起動方法

```bash
npm install     # 初回のみ
npm run dev     # 開発サーバー起動 → http://localhost:5173
```

本番用ファイルを作る場合:

```bash
npm run build   # dist/ に出力
npm run preview # 出力したファイルの動作確認
```

## 主な機能

| 要望 | 実装 |
| --- | --- |
| 複数プロジェクトを横一列で見やすく | 1プロジェクト＝1行のガントチャート。行内に営業／メカ／電気／CS の4レーンを並べて表示 |
| プロジェクトの追加は最下行 | 「＋ プロジェクト追加」で必ず一番下の行に追加され、そのまま詳細パネルが開く |
| 最優先のプロジェクトを見やすく | 行の並べ替えに対応。ドラッグ＆ドロップ／`⤒`（最優先＝一番上へ）／`↑` `↓`。一番上の行は番号が金色で強調 |
| 担当（営業・メカ・電気・CS）が分かる | 左側に担当者バッジ、タイムラインは部署ごとの色分けバー。ツールバーの「担当で強調」で特定部署だけを浮かび上がらせる |
| 直感的な UI | 今日を示す赤い縦線、土日の網掛け、日／週／月の表示切替、「今日へ」ボタン、進捗バー |
| 完了プロジェクトは別ページ | 上部タブ「完了」に移動。検索・詳細表示・「進行中に戻す」が可能 |
| 各プロジェクトの TODO リスト | 詳細パネルに TODO を追加（部署タグ・期限つき）。期限切れは赤字、達成率をバー表示 |

## 使い方

1. **プロジェクトを追加** — ツールバー右上の「＋ プロジェクト追加」。最下行に追加され、右の詳細パネルが開きます。
2. **担当と工程を入力** — 詳細パネルで部署ごとに「担当者名・開始日・終了日・進捗%」を入力すると、その場でガントバーに反映されます。
3. **並べ替え** — 行を上下にドラッグするか、行にカーソルを合わせて出るボタン（`⤒` 最優先へ / `↑` / `↓`）を使います。
4. **TODO** — 詳細パネル下部で追加・チェック・削除。部署タグと期限をつけられます。
5. **完了** — 詳細パネルの「✓ 完了にする」で完了ページへ移動します。戻したい場合は完了ページの「進行中に戻す」。

## 部署を変更したい場合

`src/constants.js` の `DEPARTMENTS` を編集すると、部署の名称・色・並び順を変更できます。
（`key` は保存データのキーなので、既にデータがある状態では変更しないでください）

```js
export const DEPARTMENTS = [
  { key: 'sales', label: '営業', short: '営', color: '#2563eb', soft: '#dbeafe' },
  ...
];
```

## 構成

```
src/
  App.jsx                  画面全体（タブ・ツールバー・状態の受け渡し）
  constants.js             部署定義・表示単位・保存キー
  hooks/useProjects.js     プロジェクトの状態管理（追加・並べ替え・完了・TODO）
  lib/date.js              日付ユーティリティ
  lib/project.js           プロジェクトのデータ構造と集計
  lib/timeline.js          ガントチャートの目盛り計算
  lib/storage.js           localStorage への保存・読み込み
  lib/sampleData.js        初回起動時のサンプルデータ
  components/
    GanttChart.jsx         ガント全体（ヘッダー目盛り・並べ替え）
    GanttRow.jsx           1プロジェクト分の行
    ProjectDrawer.jsx      詳細パネル（担当・工程・TODO）
    TodoList.jsx           TODO リスト
    CompletedPage.jsx      完了プロジェクト一覧
    DeptChip.jsx           部署バッジ
```

## データについて

保存先はブラウザの localStorage（キー: `project-gantt-board:v1`）です。
別の PC やブラウザとは共有されません。共有が必要になった場合は、この保存部分（`src/lib/storage.js`）を
サーバー API に差し替える構成にしています。
