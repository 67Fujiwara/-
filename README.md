# プロジェクト工程ボード

複数プロジェクトの進み具合を、1プロジェクト＝1行の「横一列」ガントチャートで見渡すための Web アプリです。
営業・メカ・電気・CS（カスタマーサポート）などの工程ごとに、担当者と期間を色分けして表示します。

- 開発環境: Node.js + React (Vite)
- データはブラウザの localStorage に保存されます（サーバー不要・インストール不要）

## 起動方法

```bash
npm install     # 初回のみ
npm run dev     # 開発サーバー起動 → http://localhost:5173
```

本番用ファイルを作る場合:

```bash
npm run build   # dist/ に出力
npm run preview # 出力したファイルの動作確認
```

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 横一列のガント | 1プロジェクト＝1行。行の中に工程ごとのレーンを並べて表示。行全体の期間も細い帯で表示 |
| プロジェクトの追加 | 「＋ プロジェクト追加」で必ず最下行に追加され、そのまま詳細パネルが開く |
| 並べ替え | ドラッグ＆ドロップ／`⤒`（最優先＝一番上へ）／`↑` `↓`。一番上の行は番号が金色で強調 |
| 担当が分かる | 左側に「工程＋担当者名」バッジ、タイムラインは工程ごとの色分けバー。ツールバーの「工程で強調」で特定工程だけを浮かび上がらせる |
| **工程の追加・編集** | 「工程を編集」から工程を追加・改名・色変更・並べ替え・削除できる。**全プロジェクト共通の工程**と、**そのプロジェクトだけの工程**（例：修正対応）を分けて管理できる。初期値は 営業／メカ／電気／CS |
| **立ち上げ日** | プロジェクトごとに立ち上げ日を設定でき、ガント上に赤い ◆ と破線で表示 |
| **TODO のホバー表示** | ガントの**バー（グラフ）にマウスを乗せると、その工程の TODO 一覧**がポップアップ表示（TODO が無い工程では出ません） |
| **進捗の自動同期** | 工程に紐づく TODO があれば「完了数 ÷ 件数」がその工程の進捗になり、ガントのバーにも反映。TODO が無い工程だけスライダーで手入力 |
| TODO リスト | **工程タブで切り替えて表示**（末尾の「すべて」タブで全件表示）。開始日〜終了日を付けて登録でき、終了日を過ぎた未完了は赤字、達成率をバー表示 |
| 完了ページ | 上部タブ「完了」に移動。検索・詳細表示・「進行中に戻す」が可能 |
| 表示の切替 | 日／週／月の目盛り、今日を示す赤い縦線、土日の網掛け、「今日へ」ボタン |

## 使い方

1. **プロジェクトを追加** — ツールバー右上の「＋ プロジェクト追加」。最下行に追加され、右の詳細パネルが開きます。
2. **基本情報を入力** — プロジェクト名・客先・**立ち上げ日**・メモ。
3. **担当と工程を入力** — 工程ごとに「担当者名・開始日・終了日」を入力すると、その場でガントバーに反映されます。
4. **TODO** — 詳細パネル下部の工程タブを選んで追加します。選択中の工程に紐づくので、その工程の進捗が TODO の完了率から自動計算されます。
5. **確認** — ガントのバーにマウスを乗せると、その工程の TODO 一覧がポップアップします。
6. **並べ替え** — 行を上下にドラッグするか、行にカーソルを合わせて出るボタン（`⤒` / `↑` / `↓`）。
7. **完了** — 詳細パネルの「✓ 完了にする」で完了ページへ。戻すときは完了ページの「進行中に戻す」。

## 工程（担当区分）について

ツールバーまたは詳細パネルの「工程を編集」から変更できます。設定は2つに分かれています。

**すべてのプロジェクト共通の工程**（営業・メカ・電気・CS など）
全プロジェクトの行に表示されます。ただし**日付を入力したプロジェクトだけバーが描かれます**。

**このプロジェクトだけの工程**
プロジェクトを開いた状態で「工程を編集」を押すと表示されます。「修正対応」「追加改造」など、
その案件にだけ発生した工程をここで足せます。他のプロジェクトの行には追加されません。

共通・専用どちらも次の操作ができます。

- **追加**: 工程名を入力して「＋ 追加」。色は自動で未使用の色が割り当てられます（色見本をクリックして変更可）
- **並べ替え**: `↑` `↓`。ガントのレーンの順番もこれに従います
- **削除**: `×`。その工程の担当者・期間も削除され、その工程が付いた TODO は「工程なし」に戻ります

なお、行の高さは**一番工程が多いプロジェクトに合わせて全行そろえる**ので、
専用工程を足しても他の行とずれません（工程が少ない行は空きレーンになります）。

```

  App.jsx                     画面全体（タブ・ツールバー・状態の受け渡し）
  constants.js                工程の初期値・色パレット・表示単位・行レイアウト
  hooks/useBoard.js           状態管理（プロジェクトと工程の追加・並べ替え・完了・TODO）
  lib/date.js                 日付ユーティリティ
  lib/departments.js          工程定義の生成と補正
  lib/project.js              プロジェクトのデータ構造と集計（進捗の自動計算を含む）
  lib/timeline.js             ガントチャートの目盛り計算
  lib/storage.js              localStorage への保存・読み込み（旧データの移行つき）
  lib/sampleData.js           初回起動時のサンプルデータ
  components/
    GanttChart.jsx            ガント全体（ヘッダー目盛り・並べ替え・ホバー制御）
    GanttRow.jsx              1プロジェクト分の行
    TodoHoverCard.jsx         バーにホバーしたときの、その工程の TODO 一覧
    ProjectDrawer.jsx         詳細パネル（基本情報・担当と工程・TODO）
    TodoList.jsx              TODO リスト（工程タブ切り替え）
    DeptSettingsModal.jsx     工程の設定（共通 / プロジェクト専用）
    CompletedPage.jsx         完了プロジェクト一覧
    DeptChip.jsx              工程バッジ
```

## データについて

保存先はブラウザの localStorage（キー: `project-gantt-board:v1`）です。
別の PC やブラウザとは共有されません。共有が必要になった場合は、この保存部分（`src/lib/storage.js`）を
サーバー API に差し替える構成にしています。

保存形式が変わっても、古いデータは読み込み時に自動で移行されます
（工程が未定義のデータには初期の4工程を補い、TODO の「期限」は「終了日」として引き継ぎます）。
